# 📖 Гостевая книга на Flask

Практическая работа №9: Создание гостевой книги с использованием Flask и SQLite.

## 🚀 Возможности

- Просмотр всех сообщений
- Хранение данных в SQLite
- Сортировка сообщений (новые сверху)

## 🛠️ Технологии

- Python 3.x
- Flask
- SQLite3
- HTML/CSS
